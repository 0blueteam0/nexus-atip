# AI 인터뷰 프롬프트 템플릿

## 목적
프로젝트 시작 전 AI와의 구조화된 대화를 통해 요구사항 명확화

---

## 기본 인터뷰 프롬프트

```
나는 [프로젝트 목표]를 만들고 싶어.

현재 상황:
- [기존 코드/시스템 유무]
- [사용 가능한 기술 스택]
- [시간 제약]

제약 조건:
- [기술적 제약]
- [비즈니스 제약]

이 프로젝트를 시작하기 전에 나에게 질문해줘.
요구사항을 명확히 하기 위해 5-10개 질문을 해줘.
```

---

## 질문 카테고리별 예시

### 기능 범위
- "핵심 기능 3개를 우선순위로 나열해줘"
- "MVP에서 제외해도 되는 기능은?"
- "사용자는 누구야?"

### 기술 스택
- "프론트엔드 프레임워크 선호도는?"
- "백엔드 언어 제약이 있어?"
- "데이터베이스 요구사항은?"

### 통합
- "외부 API 연동이 필요해?"
- "인증 방식은?"
- "배포 환경은?"

### 비기능 요구사항
- "예상 사용자 수는?"
- "성능 요구사항이 있어?"
- "오프라인 지원이 필요해?"

## 팁

1. **모호한 답변 피하기**: "좋은 UX" → "3초 내 페이지 로드"
2. **범위 제한**: "모든 기능" → "핵심 3개 기능만"
3. **구체적 숫자**: "많은 사용자" → "동시 100명"
