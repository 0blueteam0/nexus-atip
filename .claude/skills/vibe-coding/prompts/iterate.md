# 반복 개선 프롬프트 템플릿

## 목적
작은 단위로 기능을 요청하고 점진적으로 구축

---

## 기본 패턴

### 1. 단일 기능 요청
```
[기능A]만 먼저 구현해줘.
다른 기능은 나중에 추가할 거야.
가장 간단한 작동 버전으로 시작하자.
```

### 2. 확장 요청
```
잘 됐어! 이제 [기능B]를 추가해줘.
기존 [기능A]는 그대로 유지하고.
```

### 3. 버그 수정 요청
```
[문제 설명] 에러가 발생했어.
에러 메시지: [메시지]
예상 동작: [기대 결과]
실제 동작: [현재 결과]
```

### 4. 리팩토링 요청
```
작동은 하는데, [구체적 문제]가 있어.
[특정 부분]만 개선해줘.
기존 기능은 유지하면서.
```

---

## 효과적인 프롬프트 패턴

### 범위 제한
```
# 좋음
"로그인 버튼만 추가해줘"

# 나쁨
"인증 시스템 전체를 구현해줘"
```

### 명확한 입출력
```
# 좋음
"함수는 배열을 받아서 정렬된 배열을 반환해야 해"

# 나쁨
"데이터를 처리하는 함수 만들어줘"
```

### 컨텍스트 제공
```
# 좋음
"현재 React 18 + TypeScript 프로젝트야.
src/components/Button.tsx 파일에 있는
기존 Button 컴포넌트를 수정해줘"

# 나쁨
"버튼 컴포넌트 수정해줘"
```

## 실패 시 대응

### 컨텍스트 리셋
```
잠깐, 처음부터 다시 생각해보자.
[원래 목표]를 달성하려고 해.
지금까지 시도: [시도한 것들]
다른 접근법을 제안해줘.
```

### 단계 분해
```
[기능]이 복잡한 것 같아.
더 작은 단계로 나눠줘:
1. 먼저 [부분1]
2. 그 다음 [부분2]
3. 마지막으로 [부분3]
```

### 대안 요청
```
현재 방식이 잘 안 돼.
같은 결과를 얻는 다른 방법 3가지 제안해줘.
각각의 장단점도 설명해줘.
```
