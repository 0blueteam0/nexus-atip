# Insights

- Broad image queries such as “실손보험 영수증” can return severe noise; FDS data collection needs DOM-level inspection and relevance filtering.
- Bing Images yielded useful Korean candidates for 진료비 계산서·영수증, 세부산정내역서, 약제비 영수증, and 보험금 청구서류.
- Google Images failed through this browser tool due decode error; it remains a manual cross-check target.
- Real public images can contain PII; therefore all real-image candidates and derivatives are marked quarantine/review-required.
- Scanner derivatives should be first-class NO data, not only phone camera augmentations.
