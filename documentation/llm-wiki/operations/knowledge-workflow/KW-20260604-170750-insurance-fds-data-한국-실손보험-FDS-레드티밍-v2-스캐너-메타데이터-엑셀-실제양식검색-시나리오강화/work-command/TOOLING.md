# Tooling

- `scripts/insurance_fds_public_image_collector.py`: Bing image search extraction, download, PNG metadata, Excel index.
- `scripts/insurance_fds_real_image_redteam_generator.py`: real candidate derivative generation, scanner profiles, AF scenarios, masks, Excel index.
- `openpyxl`: Excel output.
- `PIL`: image normalization, metadata insertion, scanner/camera effects, contact sheets.
- `pytest`: regression verification.
