# Tooling

- Inspection:
  - `rg` for agent and coverage terms.
  - `Get-Content -Encoding UTF8` for Korean markdown and JS/Python source.
- Editing:
  - `apply_patch`.
- Verification:
  - Python compile for backend modules.
  - Node syntax check for frontend module.
  - Focused pytest for API behavior.
  - Runtime and launch frontend sanity scripts.
  - Git diff check for whitespace.
