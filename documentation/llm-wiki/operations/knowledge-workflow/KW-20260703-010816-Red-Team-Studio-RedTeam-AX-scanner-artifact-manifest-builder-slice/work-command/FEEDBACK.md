# Feedback

## Operator Notes

- Put scanner outputs in one workspace folder before using the builder.
- Use recognizable filenames such as `nuclei*.jsonl`, `openvas*.xml`, `trivy*.json`, `npm-audit*.json`, and `zap*.json`.
- Review unmatched files and alternatives before clicking import.
- The builder only prepares JSON. Evidence approval and report completion are later steps.
