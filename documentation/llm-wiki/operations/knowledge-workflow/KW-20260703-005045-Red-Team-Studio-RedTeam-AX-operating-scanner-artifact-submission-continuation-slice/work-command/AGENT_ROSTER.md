# Agent Roster

## Active Agent

- Codex: implementation, tests, documentation updates, evidence workflow, git staging/commit/push.

## Human Roles Required Later

- Red team operator: provide real scanner artifact files and SHA-256 manifest.
- Red team lead: approve Evidence and severity where applicable.
- Business owner: provide second severity approval for Findings.
- Executive sponsor: approve final report export.

## AI Role Boundary

- AI can plan, validate structure, normalize outputs, draft reports, and prepare retest plans.
- AI must not claim a Finding or report claim without approved Evidence and required human gates.
