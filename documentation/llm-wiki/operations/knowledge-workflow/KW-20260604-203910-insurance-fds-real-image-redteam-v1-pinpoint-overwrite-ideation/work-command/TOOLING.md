# Tooling

Used tools:

- `skill_view`: loaded FDS/security/planning workflows.
- `terminal`: started/closed knowledge workflow; inspected filesystem counts; validated JSON.
- `read_file`: inspected manifest/index/generator/test.
- `search_files`: located real-image-redteam generator and tests.
- `vision_analyze`: reviewed contact sheet for overlay symptoms.
- `write_file`: wrote report and JSON.
- `execute_code`: populated knowledge workflow evidence.

Candidate implementation tools:

- PaddleOCR/EasyOCR for OCR boxes.
- OpenCV for table/cell detection, inpainting, pixel-diff validation.
- SAM/SAM2 for mask refinement.
- VLM for QA, not primary editing.
