도구 실행 계획 / 샌드박스 정책
분석 결과 수집·검토 워크플로우
이 영역의 목적은 실행 목록을 보여주는 것이 아니라 Nuclei/OpenVAS/Trivy/SCA/npm audit/ZAP 결과를 모아 확인 후보, 심각도 분포, Evidence 후보 상태로 정리하는 것입니다. 고위험 실행은 사람이 승인·수행·검토하고, 화면은 승인된 결과를 회수해 분석 흐름으로 넘깁니다.
안전 설치 확인 버튼은 Nuclei/OpenVAS/Trivy/npm audit/OWASP ZAP의 버전 확인만 자동 구성해 실행합니다. SCA는 결과 첨부 도구라 SBOM, lockfile, 조직 SCA export를 결과 첨부로 제출합니다. 임의 스캔 명령, 능동 스캔, 관리자 준비 항목 실행은 허용하지 않습니다.
복합 도구 결과 회수는 저장된 출력 또는 운영자 첨부 결과만 읽고, 안전 정리와 도구별 결과 정리를 거친 뒤 증거 카드 후보를 만듭니다. 승인 전에는 Finding이나 보고서 주장으로 확정하지 않습니다.
복합 Evidence 후보 승인은 후보 Evidence만 승인하며, Finding 생성·심각도 승인·보고서 반영은 별도 단계로 남깁니다.
복합 Finding 초안 생성은 승인된 Evidence만 pending review Finding 초안으로 만들고, 2인 심각도 승인 전에는 Matrix와 보고서 Claim에 넣지 않습니다.
복합 Finding 심각도 2인 승인은 레드팀 리드와 업무 소유자가 같은 심각도를 승인해야 Finding이 승인되며, 보고서 생성은 Matrix gate 이후에만 진행합니다.
복합 Collection Matrix 초안은 승인된 Evidence와 2인 승인 Finding만 ready row로 구성하며 보류 row는 보고서 입력에서 제외합니다.
복합 Collection Report v2 draft는 Matrix ready와 report gate pass일 때만 한국어 Report v2 draft를 생성하고 최종 export 승인은 별도로 남깁니다.
복합 Collection 최종 export 게이트는 Report v2 draft의 report_id를 최종 게이트 패널에 자동 연결한 뒤 Executive Sponsor 승인을 받은 경우에만 내보내기를 허용합니다.
복합 Collection E2E 완료 게이트는 기존 산출물만 읽어 Evidence 승인, Finding 승격, 2인 severity 승인, Matrix ready, Report gate, export 완료를 한 번에 점검합니다.
