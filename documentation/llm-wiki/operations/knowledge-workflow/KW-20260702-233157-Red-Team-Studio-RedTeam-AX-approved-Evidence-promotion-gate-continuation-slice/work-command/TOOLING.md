# TOOLING

Used tooling:
- `rg` for targeted code searches.
- `Get-Content -Encoding UTF8` for Korean-safe file inspection.
- `apply_patch` for file edits.
- `.venv` pytest for API regression.
- `node --check` for frontend syntax.
- Project sanity scripts for Korean copy, runtime readiness, completion audit, plan contract, and accepted gate manifest.

Do not use this API as a scanner runner; it only promotes already approved Evidence to Finding drafts.
