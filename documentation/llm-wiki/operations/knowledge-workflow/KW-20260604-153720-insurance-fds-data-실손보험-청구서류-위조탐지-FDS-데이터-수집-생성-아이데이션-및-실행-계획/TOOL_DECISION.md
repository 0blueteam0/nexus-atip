# Tool Decision

- Browser: ChatGPT 공유 링크 본문 확인에 사용.
- Terminal: Firecrawl 상태, HF API, 공식 URL reachability, knowledge_workflow 실행에 사용.
- Delegate task: 데이터셋 후보 조사와 실손 청구서류 스키마 조사를 병렬화.
- Execute code: seed artifact와 evidence 파일 생성 및 JSON 파싱 검증.
- Firecrawl: localhost root는 정상이나 scrape 호출이 실패해 이번 턴에서는 browser/terminal 대체.
