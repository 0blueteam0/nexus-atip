# Insights

1. 실제 의료/보험 문서는 PII/민감정보 문제로 공개 원천이 제한되므로, 공개 영수증/OCR/KIE 데이터와 합성 실손 도메인 데이터를 결합하는 전략이 현실적이다.
2. NO/FK/AF 3계층을 분리해야 모델 학습, 평가, 법무 검토, 데이터 lineage가 명확해진다.
3. FDS 고도화는 단일 이미지 위조 탐지만으로 부족하며 문서 패키지 간 날짜/금액/기관/질병코드/계좌/행태 그래프 교차검증이 핵심이다.
4. FK 실제 사례는 원문 위조 문서보다 공개 판례/수사/보도 기반의 추상 라벨과 방어적 feature로 시작하는 것이 안전하다.
