# Insight

## 관찰

Safe install smoke and full six-tool coverage are different states. The former validates installed local commands; the latter requires SCA and service/import outputs to be attached and collected.

## 통찰

Beginner-friendly UX should keep missing/import-only tools visible in the main workflow, not only in administrator details.

## 제안

Next slices should prioritize real six-tool operating output submission and closure, not additional copy-only changes.

## 적용 가능 범위

RedTeam2 toolchain execution, toolchain run-status projection, collect-results readiness guidance.

## 후속 작업

Connect real operating outputs or approved read-only scanner services and close Evidence/Finding/Matrix/Report/export gates.
