# Tooling

Used tools:

- `rg` for source/document lookup.
- `Get-Content -Encoding UTF8` for Korean Markdown/JSON inspection.
- `apply_patch` for edits.
- `.venv\\Scripts\\python.exe` for package generation, pytest, contracts, and accepted gates.
- `node --check` for frontend syntax.

Not used:

- Docker or WSL start commands.
- OpenVAS/ZAP live network calls.
- Any scanner active scan command.
