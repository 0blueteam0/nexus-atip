# Feedback

사용자 요청 반영 사항:

- 실제 청구 서류가 이미지/카메라 촬영으로 제출되는 경우가 많다는 점을 데이터셋 설계에 반영했다.
- Stable Diffusion/ComfyUI 같은 이미지 생성형 도구 활용 필요성을 contract와 차별화 전략으로 반영했다.
- AF 합성 데이터는 label/mask/manifest로 학습 가능하게 만들었다.
- 공개 데이터와 실제/위조 문서 후보는 안전한 공개 후보 중심으로 정리했다.

추가 피드백이 필요한 부분:

- ComfyUI를 로컬로 설치/실행할지, Cloud API를 사용할지 선택 필요.
- 실제 보험사 공개 양식 crawling 범위와 저장 정책 승인 필요.
