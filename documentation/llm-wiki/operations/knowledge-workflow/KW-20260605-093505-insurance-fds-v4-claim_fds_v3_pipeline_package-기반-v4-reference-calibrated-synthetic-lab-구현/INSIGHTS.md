# Insights

- The v3 package was already unzipped; the requested zip was not present in the target directory.
- The main baseline blocker was environment portability, not pipeline logic. Windows font fallback was required.
- Real reference images are heterogeneous: portrait scans/photos, landscape crops, dense tables, low contrast, stamps, and variable backgrounds.
- Better fidelity should come from distribution calibration, not from copying real pixels or OCR text.
- Current v4 is a safe skeleton; visual fidelity remains cleaner and more regular than many real examples.
