# Insights

- The correct near-term architecture is not to immediately attach an LLM, but to freeze a backend contract node in LangGraph first.
- Demo OAuth use is feasible only as a redacted/synthetic fallback and should remain disabled in default tests.
- Replay evaluation is a good first feedback graph because it can rank next module improvements without touching production SOC systems.
- User wants code comments to be highly explanatory in Korean so later manual fine-tuning is easier.
