# Tool Decision

- Used `test-driven-development` skill because this was a new code feature and behavior contract.
- Used `systematic-debugging` skill for verification discipline and no-guess workflow.
- Used `unittest` because the implementation seed already uses Python stdlib tests.
- Used LangGraph `StateGraph` because the project direction is explicit multi-agent LangGraph workflow construction.
- Did not call any LLM provider from the new code; backend policy is contract-only in this seed.
