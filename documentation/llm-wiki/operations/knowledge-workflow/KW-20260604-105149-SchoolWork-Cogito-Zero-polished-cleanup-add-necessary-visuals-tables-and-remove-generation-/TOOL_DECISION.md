# Tool Decision

## Visual/data decision
- Do not add decorative stock images or AI-themed generated imagery. They would make the deck more generic and less premium.
- Do add practical tables and structured visual elements: policy decision matrix, adoption priority/PoC success table, KPI/financial logic table, flow/matrix/roadmap shapes in PPTX.
- Do not invent external market numbers. Use operational KPI categories instead.

## Tools used
- python-docx and python-pptx via uv for document generation.
- Structural QA script for paragraph counts, table counts, slide counts, dense boxes, out-of-bounds shapes, and meta-term scanning.
- Git for cleanup commit.
