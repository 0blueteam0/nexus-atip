# Tooling

Used:
- python-docx for DOCX generation and inspection.
- python-pptx for PPTX generation and structural inspection.
- uv for dependency-isolated execution.
- git for scoped cleanup and push planning.
- tasklist to identify WINWORD.EXE as a likely file lock cause.

Not used:
- Generated images: judged unnecessary.
- External market data: avoided because unsupported numbers would be misleading.
- LibreOffice rendering: not available in PATH.
