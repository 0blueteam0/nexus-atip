### 검증 방법
```
1. 테이블 캡션에서 출처 확인
2. 원본 논문 PDF 다운로드
3. 원본 테이블과 셀 단위 비교

```

### [!] 테이블 조작 검증 항목
- [ ] 테스트되지 않은 모델이 추가되지 않았는가?
- [ ] 원본에 없는 컬럼이 추가되지 않았는가?
- [ ] 수치가 원본과 정확히 일치하는가?
- [ ] 다른 논문 데이터가 혼합되지 않았는가?

### 5.3 용어 일관성
