# Windows 시스템 성능 최적화 보고서
## 2025-09-12

### 1. 문제 현황 분석

#### 발견된 주요 문제점
- **Node.js 프로세스 과다**: 173개 → 118개 (정상: 5-10개)
- **고아 프로세스**: 118개가 부모 프로세스 없이 실행
- **MCP 서버 설정 오류**: 20개 서버가 모두 "npx -y" 플래그 사용
- **숨겨진 프로젝트**: C:\MYCLAUDE_PROJECT 대규모 프로젝트 발견
- **메모리 사용량**: Bitdefender 1GB+ 사용

#### 성능 영향
- **CPU 사용률**: 높은 부하로 인한 시스템 응답 저하
- **메모리 누수**: 각 프로세스가 메모리를 점유하고 해제하지 않음
- **디스크 I/O**: 지속적인 NPM 패키지 다운로드로 디스크 부하
- **네트워크 대역폭**: 반복적인 패키지 다운로드로 낭비

### 2. 실행한 최적화 작업

#### 2.1 즉시 조치 사항
✅ **MCP 서버 설정 수정**
- .claude.json 파일에서 모든 "npx -y" → "npx"로 변경
- 영향받은 서버: 11개
  - mcp-installer
  - github
  - firecrawl  
  - sqlite-mcp

  - context7

  - supabase

```bash
npm cache clean --force
```

✅ **설정 파일 백업**
- 백업 파일: .claude.json.backup-20250912

#### 2.2 프로세스 정리 시도
⚠️ **부분적 성공**
- taskkill 명령 실행했으나 프로세스가 자동 재시작됨
- Claude Desktop 재시작 필요

### 3. 근본 원인 분석

#### 3.1 "npx -y" 플래그 문제
- **-y 플래그**: 캐시를 무시하고 매번 새로 다운로드
- **결과**: 각 MCP 서버 호출마다 새로운 Node.js 프로세스 생성
- **누적 효과**: 프로세스가 종료되지 않고 누적

#### 3.2 프로세스 관리 실패
- **부모-자식 관계 단절**: 고아 프로세스 118개
- **자동 재시작**: 종료해도 다시 시작되는 구조
- **예약 작업**: ClaudeJsonCleanup 작업이 문제 악화 가능

### 4. 권장 조치 사항

#### 4.1 즉시 실행 필요
1. **Claude Desktop 재시작**
   - 모든 MCP 서버가 새 설정으로 다시 로드됨
   - 기존 프로세스 정리

2. **예약 작업 비활성화**
   ```cmd
   schtasks /Change /TN "ClaudeJsonCleanup" /DISABLE
   ```

3. **Bitdefender 예외 추가**
   - K:\PortableApps 폴더를 실시간 검사 예외에 추가
   - 불필요한 스캔으로 인한 성능 저하 방지

#### 4.2 장기 개선 방안
1. **MCP 서버 최적화**
   - 불필요한 서버 비활성화
   - 자주 사용하는 서버만 활성화

2. **프로세스 모니터링**
   - monitor-node-processes.bat 정기 실행
   - 비정상 증가 시 알림 설정

3. **정기 유지보수**
   - 주 1회 NPM 캐시 정리
   - 월 1회 전체 시스템 점검
