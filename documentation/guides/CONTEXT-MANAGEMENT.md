# 컨텍스트 윈도우 관리 가이드

## 컨텍스트 윈도우란?
Claude가 한 번에 처리할 수 있는 정보의 양 (토큰 기준)

## 최적화 전략

### 1. Sub-agents 활용
복잡한 작업을 하위 에이전트에게 위임하여 토큰 절약
```
메인 컨텍스트 절약 효과: 최대 70%
```

### 2. /compact 명령어
대화 내용 압축하여 컨텍스트 확보
```
사용 시점: 컨텍스트 70% 초과 시
```

### 3. Context Editing
불필요한 정보 제거
```
성능 향상: 약 29%
```

## 권장 워크플로우

```
EXPLORE → PLAN → CODE → COMMIT
```

### 1. EXPLORE (탐색)
- 코드베이스 구조 파악
- 관련 파일 식별
- Sub-agent 활용 권장

### 2. PLAN (계획)
- 구현 단계 정의
- 위험 요소 식별
- /plan 모드 활용

### 3. CODE (구현)
- 단계별 구현
- 청크 단위 작업
- 중간 검증

### 4. COMMIT (커밋)
- 변경사항 검토
- 의미 있는 커밋 메시지
- 테스트 확인

## 컨텍스트 절약 팁

1. **파일 전체 로드 피하기**: 필요한 부분만 읽기
2. **결과 요약 요청**: 긴 출력 요약
3. **Sub-agent 활용**: 탐색 작업 위임
4. **주기적 /compact**: 긴 대화 압축
5. **Memory 활용**: 반복 정보 저장

## Memory + Context 조합
```
성능 향상: 39% (combined)
```
- 자주 사용하는 정보 → Memory 저장
- 현재 작업 정보 → Context 유지
