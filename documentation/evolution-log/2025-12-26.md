#### 2.1 Claude Code Best Practices (2025-04-18)
**6가지 권장 워크플로우**:
1. Explore, plan, code, commit
2. Write tests, commit; code, iterate, commit
3. Write code, screenshot result, iterate
4. Parallel multi-Claude sessions
5. Git worktree 활용
6. Headless 모드 활용

**핵심 원칙**:
- CLAUDE.md 활용 (프로젝트 지침)
- 컨텍스트 효율성 유지
- 자동화 및 파이프라인 통합

#### 2.2 Agent Skills (2025-10-16)
**Progressive Disclosure 3단계**:
1. **Level 1**: 이름 + 설명 (항상 로드)
2. **Level 2**: SKILL.md 전체 (필요시 로드)
3. **Level 3**: 추가 파일 (명시적 요청시)

**표준화**: agentskills.io 커뮤니티 표준

**구조 변경**: Claude Code SDK → Agent SDK
