# 케이스1_정상청구문서_수집 고충실도 육안검수 체크리스트

이 체크리스트는 해상도 확인표가 아닙니다. 보험사 제출 문서를 사람이 보듯이 보면서, 위변조 의도와 정상 영역 보존을 확인합니다.

## 공통 확인

- [ ] 파일명이 `케이스1_정상청구문서_수집` 로 시작한다.
- [ ] 문서 이미지에 보이는 필드명이 한국어다.
- [ ] 이미지 안에 합성/모델학습/제출불가 문구가 없다.
- [ ] 검은 박스, 큰 흰색 덮개, 비현실적 블록이 없다.
- [ ] 사람이 육안으로 보아도 너무 낮은 품질의 덮어쓰기처럼 보이지 않는다.
- [ ] 의도한 정상/위변조/생성 목적이 명확히 구현되었다.
- [ ] 목표 필드 외 표, 배경, 글자, 좌표, 문서관계가 깨지지 않았다.
- [ ] manifest의 라벨과 이미지에서 보이는 변화가 일치한다.

## 실패 처리

하나라도 실패하면 해당 산출물은 금융회사 납품용 학습/검증 이미지로 승격하지 않는다.
