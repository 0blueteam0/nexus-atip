# 케이스5_수집문서학습기반_LLM코딩도구_신규문서생성

case_family: `case5_llm_code_full_synthetic_generation_from_case1_learning`

## 목적

Case 1에서 확인한 한국어 필드와 문서 구조를 배운 뒤, LLM/코딩도구가 새 문서를 처음부터 생성하는 케이스다. 단, 생성물 범위에 한정한다.

## 고충실도/고품질 기준

금융회사 납품 수준의 고충실/고품질은 단순히 이미지 해상도가 높은 것이 아닙니다.
고충실도는 위변조 의도 또는 정상 수집 의도가 정확히 구현되고, 정상 문서의 나머지 부분이 깨지지 않는 것입니다.

필수 확인:

- 위변조 의도 또는 정상 수집 목적이 산출물에 정확히 반영됨
- 목표 필드 외 문서의 표, 배경, 글자, 좌표, 문서관계가 불필요하게 깨지지 않음
- 사람이 육안으로도 저품질 조작처럼 보이지 않음
- 문서 이미지에 보이는 필드명은 한국어
- 이미지 픽셀 안에 합성/모델학습/제출불가 문구 금지
- 검은 박스, 큰 흰색 덮개, 비현실적 블록 금지

- 환자명

- 요양기관명

- 청구인
