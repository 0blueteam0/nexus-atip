============================================
     K드라이브 환경 수정 실행 가이드
============================================

이 폴더에는 두 가지 수정 스크립트가 있습니다:
1. FIX-ALL-ISSUES-CMD.txt - CMD용
2. FIX-ALL-ISSUES-POWERSHELL.txt - PowerShell용

============================================
     실행 방법
============================================

[방법 1: CMD 사용]
1. Windows + R 키를 누르고 "cmd" 입력 후 Enter
2. FIX-ALL-ISSUES-CMD.txt 파일을 메모장으로 열기
3. 전체 내용 선택 (Ctrl+A) 후 복사 (Ctrl+C)
4. CMD 창에서 마우스 우클릭으로 붙여넣기
5. Enter 키를 눌러 실행

[방법 2: PowerShell 사용]
1. Windows + X 키를 누르고 "Windows PowerShell" 선택
2. FIX-ALL-ISSUES-POWERSHELL.txt 파일을 메모장으로 열기
3. 전체 내용 선택 (Ctrl+A) 후 복사 (Ctrl+C)
4. PowerShell 창에서 마우스 우클릭으로 붙여넣기
5. Enter 키를 눌러 실행

============================================

============================================

1. 과도한 파일 정리 (150개 → 50개 이하)
   - FIX-*, TEST-*, VERIFY-*, RUN-* 등 임시 파일 이동

2. Bash 환경 수정
   - shell-snapshots 디렉토리 생성

3. 시스템 테스트
   - Claude 버전 확인
   - MCP 서버 목록 확인
   - 최종 파일 개수 확인
